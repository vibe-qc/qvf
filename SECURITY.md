# Security and privacy reports

Send security vulnerabilities and accidental private-data disclosures to
**mpei@vibe-qc.com**. Include the affected QVF/toolkit version, a minimal
reproducer and the impact. Share sensitive files privately; do not put them
in a public issue or pull request.

QVF follows the toolset's shared
[security reporting and disclosure policy](https://github.com/vibe-qc/vibe-qc/blob/main/SECURITY.md).
The email contact works independently of repository visibility.
