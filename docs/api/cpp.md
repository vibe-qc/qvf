# C++ and C API reference

The reference of the public headers in
[`cpp/include/qvf/`](../../cpp/include/qvf/) is generated by Doxygen from
[`cpp/Doxyfile`](../../cpp/Doxyfile) when the site is built:

**[Open the C++ and C API reference](cpp-reference/index.html)**

It covers the C++ library (`qvf::Writer`, `qvf::Reader`, `qvf::Editor`, the
typed manifest model, validation, units and the generated typed kinds) and
the C ABI 1 header [`qvf_c.h`](../../cpp/include/qvf/qvf_c.h). The headers
document their declarations with plain comments, and an input filter
(`scripts/doxygen_filter.py`) gives them to Doxygen without changing a
header. The [library guide](../library_guide.md) shows how the C++ pieces
fit together, the [C ABI guide](../c_api.md) covers the C entry points and
their ownership rules, and the [specification](../../spec/qvf-format-spec.md)
is normative where a comment is shorter.
